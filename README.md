## 📂 Featured Projects

### 🔹 ShopQR: QR Menu & Digital Storefront SaaS
Lets local merchants launch mobile-optimized catalogs in minutes.
- Dynamic cataloging, QR code generation, WhatsApp ordering, analytics, custom themes
- AI-powered product descriptions using the **Google Gemini API**
- bcrypt hashing, JWT sessions, brute-force lockouts, IP rate limiting, owner-scoped authorization
- Free vs. Pro plan logic

**Stack:** `Next.js 15` `Express.js` `MongoDB` `Gemini API` `Cloudinary` `Vercel` `Render`

🔗 [Live Demo](https://your-shopqr-live-link) · [Source Code](https://github.com/manashwebdev/YOUR-SHOPQR-REPO)

### 🔹 DevProof: Developer Credibility Platform
Verifies developer claims using real GitHub activity.
- Claim verification, resume diffing, and project health scoring
- GitHub activity analyzer that generates **Trust Scores** and evidence ratings
- PDF resume upload and parsing, with history stored in MongoDB

**Stack:** `React.js` `Vite` `Node.js` `Express.js` `MongoDB` `GitHub API` `Tailwind CSS` `Framer Motion`

🔗 [Live Demo](https://your-devproof-live-link) · [Source Code](https://github.com/manashwebdev/YOUR-DEVPROOF-REPO)

### 🔹 ScopeShield: Shared Scope-Agreement Workspace
Helps freelancers and clients agree on deal terms, with dual-party approval for every change.
- Tokenized private sharing so clients can respond without creating an account
- Interactive **Client Orbit** visualization built with the HTML5 Canvas API
- scrypt-hashed credentials, JWT sessions, login rate limiting

**Stack:** `React.js` `Vite` `Node.js` `Express.js` `MongoDB` `JWT` `Canvas API` `Vercel` `Render`

🔗 [Live Demo](https://your-scopeshield-live-link) · [Source Code](https://github.com/manashwebdev/YOUR-SCOPESHIELD-REPO)
